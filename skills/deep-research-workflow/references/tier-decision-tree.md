# DR Tier Decision Tree

> Phase 0 强制执行：5 个 yes/no 题机械判断 Tier，避免凭直觉选档。

---

## 5 题决策流程

```
Q1: 这是单点 fact-check 还是多角度调研？
    单点 (查 1 个事实/数字/价格) → T0
    多角度 → 继续

Q2: 决定影响范围？
    一次性使用 (问完即弃) → T1
    持续影响 (要落盘做参考) → 继续

Q3: 决策可逆性？
    可逆 (可改方案) → T2
    不可逆 (迁移/合同/对外发布) → 继续

Q4: 受众是谁？
    自己用 / 内部团队 → T3
    给客户/合作方/团队公开看 → 继续

Q5: 战略级 (影响 6+ 个月规划)？
    否 → T3
    是 → T4
```

---

## Tier 速览表

| Tier | 用例 | 时间 | Anthropic Token | Phase 数 |
|------|------|------|------|----------|
| **T0 Spot Check** | 单点 fact-check（"NZ 海归 2025 多少人？"）| 1-2 min | ~3K | 1 |
| **T1 Light** | 摸底（"竞品有哪几家？"）| 5-10 min | ~15K | 3 |
| **T2 Standard** | 技术选型/产品调研（默认）| 15-30 min | ~80K | 6 |
| **T3 Deep** | 不可逆决策/客户报告 | 45-90 min | ~250K | 8 |
| **T4 Strategic** | 战略级/HTML 演示 | 2-4h | ~600K-1M | 10 |

## Tier 决策矩阵 — 应用场景示例

### T0 触发示例
- "Pickaxe 月费多少？"
- "NZ 2026 Gateway Test 法案哪天生效？"
- "GPT-5 上下文长度是多少？"
- "Cursor Pro 价格 2026 调整了吗？"

### T1 触发示例
- "做一个移动端 OCR APP，市面上有哪些竞品？"
- "Notion AI vs Claude Project 哪个适合写作？"
- "新西兰房地产中介 SaaS 平台都有谁？"

### T2 触发示例（默认）
- "PDT 该不该接入 Mem0？做技术选型"
- "新西兰华人短视频内容方向怎么定？"
- "我要从 Vercel 迁到 Cloudflare，先评估"
- "Bot 框架横评（OpenClaw vs Bot-Press vs n8n）"

### T3 触发示例
- "海外创作者教练新产品调研（要给客户看）" ✓ 典型 T3 用例
- "Onsite vs Online 战略决策"
- "Bot 平台 A → Bot 平台 B 迁移决策"
- "下一年 6 个月路线图"（自用但持续 6 个月）

### T4 触发示例
- "公司 5 年商业化路径（给投资人看）"
- "高端社群 5 年战略（给董事会/委员会决议）"
- "新市场出海评估（给团队 + 法务 + 投资人）"

## 升降级规则

### 自动升级触发
- 任务进入 T2/T3 后发现"需要给客户看" → 升 T3
- 任务进入 T3 后发现"决策影响 ≥6 个月" → 升 T4
- 任意 Tier 发现"30% 已使用 token 但还在 Phase 1.5" → 警告可能需升级（Phase 复杂度被低估）

### 自动降级触发（Token 预算保护）
- 累计 token 超过预算 80% 时弹出选项：
  - T4 → T3：跳过 Multi-Pass 综合，单 Pass
  - T3 → T2：跳过 Phase 2.6 cross-validation
  - T2 → T1：跳过 Gemini DR，改用 WebSearch
- 用户拒绝降级 → 提示"按当前路径预计还需 N 倍预算"，最终决策权交用户

### 禁止降级的场景
- T3+ 涉及客户交付（已签合同/已承诺给对方看）→ 禁止降到 T2，宁可慢
- T4 涉及法律/合规（合同/监管申报）→ 禁止降到 T3，宁可慢

## 模式手动覆盖

用户可以显式指定 Tier，跳过决策树：

```
"做个 T1 调研：[topic]"     → 强制 T1
"用 T3 deep 研究：[topic]"  → 强制 T3
"T4 战略级：[topic]"        → 强制 T4
```

显式覆盖时仍执行 5 题但只用作记录，不阻断。

## Tier 选择不当的常见症状

| 症状 | 可能选低了 | 可能选高了 |
|------|---------|---------|
| 报告交付后客户问"为什么没考虑 X" | ✓ T2 选成了 T1 | |
| 报告很厚但用户只看摘要 | | ✓ T3 选成了 T4 |
| Critic 找出 ≥10 个矛盾/空话 | ✓ 至少差一档 | |
| 写 4h 但实际就是 fact-check | | ✓ T3 应该是 T0/T1 |
| Token 烧光还没到 Phase 3 | ✓ Phase 复杂度低估 | ✓ Tier 选高了 |
